# ثروة — لعبة المدن والعقارات (أونلاين)

لعبة لوحية جماعية: اشترِ المدن العربية، عمّر بيوت وفنادق، تبادل وأقرض واعمل مزادات، وآخر واحد بدون إفلاس بيربح.
تصميم وأسماء ولوح وبطاقات ورسومات أصلية (مو نسخة عن أي لعبة). كل الواجهة بالعربي.

## التشغيل
```
node tharwa-game/server.js
```
بعدها افتح: http://localhost:8700 — ما في أي مكتبات لازم تنزل (Node فقط).

## الدول والأعلام
- **الدول العربية بس:** 22 دولة (دول الجامعة العربية) بأعلامها (SVG بملف `public/flags.js`)، لكل دولة 3 مدن.
- اللوح فيه 8 دول: **سوريا والأردن والعراق دايماً موجودين** (أغلى 3 دول، بهالترتيب)، والباقي 5 دول عربية عشوائية.
- صاحب الغرفة **بيختار الدول بنفسه**: بيضغط على أي دولة بلوحة «دول اللوح» وبيختار بدالها من الدول العربية،
  أو بيضغط «🎲 دول عشوائية» ليجيب 5 دول عربية جديدة (سوريا والأردن والعراق بيضلّوا ثابتين).

## شو شغّال (مجرّب)

- **المبلغ الابتدائي: 500 / 1000 / 1500 / 2000 / 2500 / 3000.**

  البناء بالتساوي، الرهن، ترتيب عشوائي.
- كل لاعب بيختار قطعته: سيارة، طيارة، سفينة، تاج، صاروخ، ألماسة، نجمة، قبعة.
- النرد والدبل، السجن، الضرائب، **بطاقات «حظ» (20 بطاقة) و«خزنة» (19 بطاقة)**.
- شراء، **مزاد البنك**، إيجارات، بيوت وفنادق.
- **🏦 الرهن**: بتاخد نص السعر من البنك وبتفكّه بـ +10%.
- **🔨 بيع عقارك بالمزاد**: بدورك، بتحط أقل سعر (اختياري)، الكل بيزاود والمصاري بتوصلك إنت.

  بيقدر يسدّد بكير، وإذا ما سدّد بوقتها بيصير المبلغ دين عليه.
- 🤝 صفقات (عقارات + مصاري)، ديون وإفلاس، دردشة، متفرّجين، لاعبين آليين بيقبلوا/بيرفضوا صفقات وقروض.
- الرسومات: أيقونات مرسومة لكل خانة، نرد ثلاثي الأبعاد، قطع بتنط عاللوح، بيوت وفنادق، بطاقات بتنقلب،

### بعد ما نشتري الدومين (مخطط له)
1. نضيف الدومين لحساب Cloudflare الخاص فيك (أو نشتريه منه مباشرة).

## النشر أونلاين (أصحابك بيدخلوا من أي مكان بلا أي برنامج)
اللعبة جاهزة للاستضافة على **Render** (في خطة مجانية): `package.json` + `render.yaml` موجودين، وما في مكتبات.

1. **GitHub** (حساب مجاني): اعمل مستودع جديد اسمه `tharwa` (ممكن Private).
2. ارفع ملفات مجلد `tharwa-game` عليه — يا إما بالسحب والإفلات من صفحة المستودع («uploading an existing file»)،
   يا إما ابعت رابط المستودع لـ Claude وهو بيرفعهن بـ git (بيطلب منك تسجّل دخول GitHub بالمتصفح مرة وحدة).
3. **Render** (render.com): سجّل دخول بحساب GitHub ← **New ← Blueprint** ← اختار مستودع `tharwa` ← **Apply**.
4. بعد دقيقتين بيطلعلك رابط متل `https://tharwa-xxxx.onrender.com` — هاد الرابط اللي بتبعته لأصحابك.

ملاحظات الخطة المجانية:
- إذا ما حدا لعب 15 دقيقة السيرفر بينام، وأول فتحة بعدها بتاخد حوالي دقيقة.
- الغرف بتنمسح إذا السيرفر نام أو انعاد نشره (اللعبة ما بتخزّن شي على قرص).
- أي تعديل بترفعه على GitHub بينتشر لحاله.
- فيك بعدين تربط دومين متل `game.serva-s.com` من إعدادات Render (Custom Domain) — مجاناً.

الحماية المضافة للنت: حد 300 غرفة، 40 متفرج بالغرفة، 10 غرف/دخول بالدقيقة لكل عنوان، وعناوين جهازك ما بتنعرض للزوار.

## الحسابات ولوحة التحكم
- **الحسابات:** أي حدا بيقدر يعمل حساب من «إنشاء حساب» (اسم مستخدم إنكليزي صغير 3–20، كلمة سر 6+). الضيوف لسا بيقدروا يلعبوا باسم بس.
  - صاحب الحساب بيدخل الغرف باسمه وصورته ولونه وقطعته المفضّلة، وبيجمع **نقاط** (لكل لعبة + للفوز).
  - بروفايل عام: `/u/اسم_المستخدم` (الصورة، النبذة، النقاط، الألعاب، نسبة الفوز، آخر الألعاب).
  - الإعدادات: `/settings` (الاسم، النبذة، 24 صورة + قطع اللعبة، اللون، القطعة، تغيير كلمة السر، حذف الحساب).
- **أول أدمن:** **أول حساب بينعمل بالموقع بيصير أدمن تلقائياً.** كمان أي اسم مستخدم بتحطه بمتغيّر `ADMIN_USERS` (مفصولين بفاصلة) بيصير أدمن لما يسجّل.
- **لوحة التحكم:** `/admin` (للأدمن بس — غيرهم بيشوف «الصفحة مو موجودة»):
  نظرة عامة (أرقام + رسم آخر 14 يوم)، المستخدمين (بحث، إيقاف/فك، أدمن، نقاط ± مع سبب، كلمة سر مؤقتة، حذف)،
  الغرف (تفرّج/سكّر)، الإعدادات (إعلان أعلى الموقع، وضع الصيانة، فتح/سكّر التسجيل، إعدادات الغرف الافتراضية، قواعد النقاط)،
  الإعلانات (`home_top` / `home_bottom` / `room_side` — صورة+رابط أو كود HTML بإطار معزول)، الألعاب (قائمة جاهزة لألعاب جديدة)، والسجل (كل عملية أدمن مين عملها وإيمتى).
- **الأمان:** كلمات السر مشفّرة بـ scrypt + salt، الجلسة بكوكي HttpOnly + SameSite=Lax (+ Secure على https)، حد للمحاولات على الدخول والتسجيل،
  رفض أي طلب تعديل جاي من موقع تاني، وكل طلب أدمن بيتفحص صلاحيته بالسيرفر.

### وين بتنحفظ البيانات؟
- **محلياً (على جهازك):** بملف `tharwa-game/data/local.json` (ما بينرفع على GitHub). بتقدر تغيّر مكانه بـ `DATA_FILE`.
- **أونلاين (Render):** قرص Render المجاني **بينمسح** كل ما ينام السيرفر أو ينعاد نشره، فلازم قاعدة بيانات برّا: **Neon (Postgres مجاني)**.

### ربط Neon (خطوة بخطوة، مرة وحدة)
1. ادخل على https://neon.tech واعمل حساب مجاني، بعدين **New Project** (اختار منطقة قريبة، مثلاً Frankfurt).
2. من **Connection Details** انسخ الرابط اللي بيبلّش بـ `postgresql://…` (خليه على وضع *Pooled connection*).
3. بـ Render: افتح خدمة **tharwa** ← **Environment** ← **Add Environment Variable**:
   - `DATABASE_URL` = الرابط اللي نسخته (**سرّي — لا تحطه بالكود ولا تبعته لحدا**).
   - (اختياري) `ADMIN_USERS` = أسماء مستخدمين بدك ياهن أدمن، مثلاً `fadi,sami`.
   - (اختياري) `COOKIE_SECRET` = أي نص عشوائي طويل (بيقوّي تشفير الجلسات؛ إذا غيّرته كل الناس بيطلعوا من حساباتهن).
4. احفظ — Render بيعيد النشر لحاله، بيركّب حزمة `pg`، والسيرفر بيعمل الجداول لحاله أول مرة.
5. افتح الموقع واعمل حسابك **أول وحدة** ليصير حسابك هو الأدمن، وبعدين ادخل على `/admin`.

### متغيّرات البيئة
| المتغيّر | شو بيعمل |
|---|---|
| `DATABASE_URL` | رابط Postgres (Neon). إذا موجود، كل البيانات بتنحفظ فيه. |
| `ADMIN_USERS` | أسماء مستخدمين بيصيروا أدمن وقت التسجيل (مفصولين بفاصلة). |
| `COOKIE_SECRET` | اختياري — بيدخل بتشفير رموز الجلسات. |
| `DATA_FILE` | للتجربة المحلية بس — مكان ملف JSON بدل `data/local.json`. |
| `GOOGLE_CLIENT_ID` | معرّف تطبيق Google (إذا مو موجود، زر Google ما بيظهر). |
| `GOOGLE_CLIENT_SECRET` | السر تبع تطبيق Google (**سرّي**). |
| `PUBLIC_URL` | اختياري — عنوان الموقع، مثلاً `https://tharwa.onrender.com` (إذا ما حطيته بيتحسب من الطلب). |

### الإيميل واسم المستخدم
- الحسابات الجديدة بكلمة سر لازم يكون إلها **إيميل** (ما بيظهر لحدا). الدخول بـ **اسم المستخدم أو الإيميل**.
- الحسابات القديمة بلا إيميل بتضل شغّالة، والإعدادات بتذكّر صاحبها يضيف إيميل.
- اسم المستخدم بيتغيّر من الإعدادات **مرة كل 30 يوم** (مش الأسماء المحجوزة). الأدمن بيقدر يغيّر أي اسم من لوحة التحكم، حتى للأسماء المحجوزة (مثل `serva`)،
  وكمان أي اسم محجوز موجود بـ `ADMIN_USERS` بينقبل وقت التسجيل.

### الدخول بحساب Google (خطوة بخطوة، مرة وحدة)
1. ادخل على https://console.cloud.google.com واعمل **مشروع جديد** (New Project) باسم «ثروة».
2. من القائمة: **APIs & Services ← OAuth consent screen**:
   - اختار **External** واضغط Create.
   - App name: **ثروة** · User support email: إيميلك · Developer contact: إيميلك.
   - Scopes: خليها الافتراضية (`openid`, `email`, `profile`) — كمّل وحفظ.
   - بعد ما تجرّب، اضغط **Publish app** ليقدر أي حدا يدخل (مش بس حسابات التجربة).
3. **APIs & Services ← Credentials ← Create Credentials ← OAuth client ID**:
   - Application type: **Web application** · Name: ثروة.
   - **Authorized redirect URIs** ← Add URI:
     - `https://serva-g.com/api/auth/google/callback` (الموقع الأساسي)
     - (اختياري، للنسخة القديمة) `https://tharwa.onrender.com/api/auth/google/callback`
   - اضغط Create وانسخ **Client ID** و **Client secret**.
4. بـ Cloudflare: Workers & Pages ← **tharwa** ← Settings ← Variables and Secrets ← Add:
   - `GOOGLE_CLIENT_ID` = الـ Client ID (نوع Secret أو Text)
   - `GOOGLE_CLIENT_SECRET` = الـ Client secret (نوع **Secret**)
5. اضغط Deploy ← بيطلع زر «المتابعة بحساب Google» بصفحة الدخول والتسجيل.
- ملاحظة: Google Cloud بيطلب تفعيل التحقق بخطوتين (2-Step Verification) على حساب Google قبل ما يفتح.
- كيف بيشتغل: إذا حساب Google مربوط ← بيدخل. إذا في حساب بنفس الإيميل المؤكَّد ← بينربط وبيدخل. إذا جديد ← بيختار اسم مستخدم بس (الإيميل والاسم والصورة من Google).
- الحسابات الموقوفة ما بتقدر تدخل بـ Google كمان.
